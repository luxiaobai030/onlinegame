# 🌐 双人游戏合集 · 网页版

浏览器里就能玩的双人游戏合集：**自己开房间，把链接发给朋友就能一起玩** ——
不用装微信、不用注册账号、**也不用自己架服务器**。
9 款经典双人游戏，规则和界面与小游戏版共用同一份代码。

## 怎么玩

1. 打开网页，点一款游戏 →「邀请好友联机对战」；
2. 点「邀请好友」，**邀请链接自动复制**，微信/QQ 发给朋友；
3. 朋友点开链接就进房，两个人各点一下「准备」，1 秒后自动开局。

同一台手机两个人轮流玩也行：选游戏时点「同屏双人」。

## 怎么弄成"自己的网址"（GitHub Pages，免费、不用信用卡）

1. 打开 GitHub 上这个仓库 → `Settings` → 左边找 `Pages`；
2. `Source` 选 `Deploy from a branch`，`Branch` 选 `main`，目录选 `/ (root)`，点 `Save`；
3. 等 1 分钟左右，网址就是 `https://<你的用户名>.github.io/onlinegame/`；
4. 手机浏览器打开这个网址就能玩，发给朋友点开就进房。

整个网页是纯静态的，不需要任何后端、也不需要数据库。

## 怎么在本机试

需要 Node.js。在本目录执行：

```bash
node server.js
```

然后打开 `http://localhost:8080`（同一个 Wi-Fi 下的朋友用 `http://你的电脑IP:8080`）。

## 联机是怎么实现的

- 网页本身是纯静态的，**借公共 MQTT 代理当中转**（`broker.emqx.io` 等，免注册、免信用卡），
  自带一串备用代理，一个连不上就自动换下一个；
- 房间里**第一个进来的浏览器兼任"服务器"**：维护谁在房里、谁准备了、什么时候开局，
  其他人只发自己的操作、听广播；
- 掉线靠 MQTT 的"遗嘱消息"：谁把页面关了/断网了，代理由自动替他广播一句，另一端马上知道。

代价和限制：

- **同一个房间的人必须同时在线**，没有"离线托管"；
- 房主关掉页面，这间房就散了（其他人会收到提示）；
- 网速不吃紧：所有游戏都是回合制，点一下传一条小消息，慢半秒不影响；
- 公共代理偶尔会抖一下，重进房间即可。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `index.html` | 网页入口：一块画布，竖屏等比缩放，手机电脑都能玩 |
| `web/boot.js` | 浏览器适配：一个假的 `wx` 对象 + 极简 `require`（相对本目录取文件，放子目录也能跑） |
| `web/mqtt-lite.js` | 极简 MQTT 客户端（只实现用得到的几个包，零依赖） |
| `web/net-mqtt.js` | 网页版联机层，接口和 `services/net.js` 完全一致 |
| `web/net-web.js` | 备用联机层：连自己架服务器的 WebSocket（配合 `server.js` 用） |
| `server.js` | 备用：托管静态文件 + 自己当联机服务器（不想用公共代理时用它） |
| `games/core/*.js` | 9 款游戏的**纯逻辑内核**（不依赖任何平台，可单测） |
| `minigame/` | 画布界面层：场景、棋盘、按钮、拖放 |
| `utils/` | 房号、客户端 ID、可复现随机、玩家形象 |
| `tests/` | 自动化测试（Node 直跑，无框架） |

这份代码原本是微信小游戏，网页版就是从同一个项目分出来的：
规则（`games/core`）和界面（`minigame/`）一行都没改，只把联机那一层换掉了。

## 跑测试

```bash
node tests/cores.test.js        # 9 款游戏的规则
node tests/minigame.test.js     # 界面层：菜单、触摸、拖放、结算
node tests/session.test.js      # 对局存档
node tests/first-player.test.js # 开局先手
node tests/draw.test.js         # 文字排版
node tests/web.test.js          # 自己架服务器那套的端到端（真起服务器、真连 WebSocket）
node tests/mqtt.test.js         # 公共代理那套的端到端（**要联网**，19 项）
```

`tests/mqtt.test.js` 会真的连上公共代理，把建房、加入、准备、开局、双向消息、掉线、房主离开跑一遍；
它需要 Node 22 以上（自带 WebSocket），也需要能上外网。

## 几件要知道的事

- 房间号 6 位；每局玩家 1 先手，点「再来一局」时两人轮换先手。
- 网页里没有微信转发，所以「邀请好友」是复制链接；网址里的 `?game=xxx&room=YYYYYY` 也能直接进房。
- 同屏双人模式也在：一台机器上两个人轮流点，交接时会自动遮屏。
