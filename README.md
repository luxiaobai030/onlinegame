# 🌐 双人游戏合集 · 网页版

浏览器里就能玩的双人游戏合集：**自己开房间，把链接发给朋友就能一起玩**，不用装微信、不用注册账号。
9 款经典双人游戏，规则和界面与小游戏版完全共用同一份代码。

## 怎么玩（本地）

需要 Node.js。在本目录执行一条命令：

```bash
node server.js
```

终端会打印两个地址：

- `http://localhost:8080` —— 自己先看看；
- `http://172.x.x.x:8080` —— **同一个 Wi-Fi** 下的朋友用这个。

玩法：首页点一款游戏 → 「邀请好友联机对战」→ 建房后点「邀请好友」，
**邀请链接会自动复制到剪贴板**，发给朋友（微信、QQ 都行）点开就进房。
两个人各点一下「准备」，1 秒后自动开局。

## 怎么让异地的朋友也能进来

上面的 `172.x.x.x` 只在同一个 Wi-Fi 里有效。要让外网的朋友连上，把这份代码丢到任意能跑 Node 的平台上，
拿到的 `https://xxxx` 网址直接发给朋友就行——网页会自动用同一个域名建立联机通道，不用改任何配置。

### 部署到免费平台

零依赖、零数据库，平台只要满足两件事：**能跑长驻的 Node 进程** + **支持 WebSocket**。

- **Northflank**（免费档叫 Sandbox，页面上写明「不休眠」）：新建 Service → 连上这个 GitHub 仓库 →
  启动命令 `node server.js` → 端口填 `8080`。
- **Render**（$0 免费实例，512MB 内存）：New → Web Service → 连仓库 → Start Command 填 `node server.js`。
  注意它闲置 15 分钟会睡着，下次有人连要等半分钟左右唤醒，**睡着的时候房间会丢**。

> 别用 Vercel / Netlify / Cloudflare 这类纯 serverless 平台：它们只能跑短命的小函数，
> **撑不住长连接的 WebSocket**，放上去房间会直接连不上。

端口不用改代码：`server.js` 会自动读平台给的 `PORT` 环境变量。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `server.js` | 联机服务器：托管网页 + 房间管理 + 转发对局消息（零依赖，WebSocket 握手与编解码都是自己实现的） |
| `web/index.html` | 网页入口：一块画布，竖屏等比缩放，手机电脑都能玩 |
| `web/boot.js` | 浏览器适配：一个假的 `wx` 对象 + 极简 `require` |
| `web/net-web.js` | 网页版联机层，接口和 `services/net.js` 完全一致 |
| `games/core/*.js` | 9 款游戏的**纯逻辑内核**（不依赖任何平台，可单测） |
| `minigame/` | 画布界面层：场景、棋盘、按钮、拖放 |
| `utils/` | 房号、客户端 ID、可复现随机、玩家形象 |
| `tests/` | 自动化测试（Node 直跑，无框架） |

**为什么还有个 `minigame/` 目录**：这份代码原本是微信小游戏，网页版就是从同一个项目分出来的。
规则（`games/core`）和界面（`minigame/`）**一行都没改**，只是把联机那一层换成了自己服务器。
`services/net.js` 是微信云开发版的联机实现，网页版不用它（被 `web/net-web.js` 顶替了），
保留是因为共用的测试套件会跑到它。

## 跑测试

```bash
node tests/cores.test.js        # 9 款游戏的规则（182 项）
node tests/minigame.test.js     # 界面层：菜单、触摸、拖放、结算（132 项）
node tests/session.test.js      # 对局存档（19 项）
node tests/first-player.test.js # 开局先手（19 项）
node tests/draw.test.js         # 文字排版（9 项）
node tests/web.test.js          # 服务器与房间流程端到端（43 项）
```

`tests/web.test.js` 会真起一个服务器、真用 WebSocket 连上去，
把建房、加入、准备、开局、双向消息、掉线、满员、房间号错误全跑一遍。

## 几件要知道的事

- 联机是"娱乐级"的：服务器只负责转发操作，两端各自按同一份动作重放；都是回合制，不吃网络延迟。
- 房间号 6 位、每间房最多 2 人；每局都由玩家 1 先手，点「再来一局」时两人轮换先手。
- 网页里没有微信转发，所以「邀请好友」是复制链接；网址里的 `?game=xxx&room=YYYYYY` 也能直接进房。
- 同屏双人模式也在：一台机器上两个人轮流点，交接时会自动遮屏。
